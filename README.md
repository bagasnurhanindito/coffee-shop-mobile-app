# ☕ Coffee Shop Order App (Full-Stack)

Aplikasi pemesanan kedai kopi berbasis *mobile* (*Full-Stack*) yang memungkinkan pelanggan melihat menu, mengelola keranjang, dan melakukan pemesanan. Proyek ini memisahkan arsitektur *frontend* dan *backend* untuk skalabilitas yang lebih baik.

## 🚀 Fitur & Arsitektur Sistem
*   **Mobile Frontend:** Dibangun menggunakan **React Native** dan **Expo** untuk menghasilkan antarmuka aplikasi *mobile* yang mulus dan responsif di platform Android maupun iOS.
*   **RESTful API Backend:** Menggunakan **Node.js** dan framework **Express.js** untuk menangani logika bisnis, otentikasi, dan rute API pemesanan.
*   **Database NoSQL:** Menggunakan **MongoDB** (melalui Mongoose) untuk menyimpan data produk, riwayat pesanan, dan profil pengguna secara fleksibel dan cepat.

## 📁 Struktur Repositori
*   `Front-end/`: Source code aplikasi mobile React Native (Expo).
*   `backend/`: Source code server Node.js dan konfigurasi database MongoDB.
